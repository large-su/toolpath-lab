# 架构

## 分层与依赖方向

```
   electron/main.mjs           独立窗口（只负责拉起后端并装窗口）
        │  HTTP / JSON
      server ─────────┐
        │             │
   ┌────┴────┐     export
   │         │        │
planning ── simulation ┘
   │            │
   └──► core ◄──┘
        ▲
        │ 静态文件
      web（原生 ES 模块 + three.js）
```

依赖只有一个方向。`core` 不认识任何其它层，`planning` / `simulation` / `export` 只依赖 `core`，
`server` 组装全部，`web` 只通过 HTTP 说话，`electron` 只负责窗口。由此得到三个好处：

- 刀路算法可以脱离界面单独跑（`examples/headless_plan.py`）；
- 换传输层（CLI、gRPC、ROS 节点）不需要动算法；
- 把 `core` + `planning` 搬进别的项目不会拖入框架依赖。

## 各层职责

### core —— 领域层

| 模块 | 职责 |
| --- | --- |
| `parameters.py` | `ParameterSpec` / `ParameterSet`：声明式参数（类型、范围、默认值、单位、中文标签、显隐条件、选项的 disabled），同时驱动界面、校验与文档 |
| `tool.py` | 刀具：类型（平底刀 / 球头刀）、直径、长度，由类型推出的**足迹半径**（刀路相对轮廓的偏置量）、**回转轮廓** `segments()`（给三维显示旋成实体）与球头刀的残留高度 |
| `region.py` | 区域形状：方形、圆形与**模型投影轮廓**（凸包 / 包围盒 + 偏置），统一输出逆时针边界多边形 |
| `surface.py` | **加工面**：平面 / 斜面 / 波浪面 / 导入模型，对外只回答一件事——`heights(xy)` 给出该 XY 处的 Z；另给出 `sample_extremes()`（安全平面）与 `warnings()`（Z-map 被放宽等） |
| `stock.py` | **毛坯**：不使用毛坯 / 模型的最小六面体包容体（轴对齐包围盒），只回答 `box()`（六个边界）与 `top_mm`（顶面高度 = 分层粗加工的起点） |
| `mesh.py` | **导入模型**：STL 解析（二进制 / ASCII）、XY 投影轮廓、Z-map **高度场**（`pick` 取最高面或最低面）、进程内的模型库 `ModelLibrary` |
| `path.py` | `Move`（切削/连接/快移 + 进给）与 `Toolpath`（统计、载荷） |
| `registry.py` | 通用能力注册表（区域形状、加工面、策略共用） |
| `payload.py` | 请求字典 → 领域对象的拆解工具 |

### planning —— 策略层

- `base.py`：`PlanningContext`（刀具 + 区域 + 加工面 + 毛坯 + 参数）与 `Planner` 基类；固定的安全高度与快移速度也在这里。
  加工面把 `to_positions()` 从"补一排 Z = 0"变成"Z 取自加工面"，`safe_z_mm` 则自动抬到
  "加工面最高点与毛坯顶面取高者"之上；分层加工另配 `level_move()`（水平层切削）、
  `rapid_over()`（抬刀横移）与 `plunge_to()`（进给下刀）；
- `geometry2d.py`：`scanline_intervals`（直线与多边形求交、偶奇配对）与多边形规范化——
  栅格刀路只靠这一个几何操作就能支持任意形状；
- `raster.py`：往复与单向两种模式。平面加工面下一刀两个端点（与以前完全一致）；
  非平面加工面下每条刀线按 `sample_step_mm` 取点，Z 逐点跟随，于是同一段代码就能做三轴曲面加工；
  选了毛坯并把 `depth_per_pass_mm` 设成大于 0 时，再自动变成分层粗加工（见下）。

### simulation —— 时间层

`build_timeline` 把每段运动按自己的进给速度换算成时间（t = 弧长 / 进给），在弧长上重采样并限制
总采样数（默认 4000），同时保留每段边界，所以播放不会跨段插值。载荷里 `times` / `positions`
是逐采样数组，`kind_runs` / `move_runs` 是游程编码。

### export / server / web / electron

- `export/gcode.py`：G21 / G90 / G17 + G0 / G1 带 F 的最常见 ISO 子集；
- `server`：标准库 `ThreadingHTTPServer`。`schema.py` 是唯一的请求校验入口（把 `model.id` 解析成模型库里的对象），
  `service.py` 组装响应，`catalog.py` 生成能力目录，`app.py` 只做路由与错误码映射
  （400 参数错误 / 422 几何不可行 / 404 / 405）；导入的模型库挂在服务实例上（`ToolpathLabServer.models`，重启即清空）；
  静态文件只从 `web/` 提供并做了路径穿越防护；
- `web`：`panel.js` 依据目录生成控件（模型一节另外画：上传 / 选择 / 删除），`viewport.js` 负责 three.js 场景与相机，
  `playback.js` 是纯逻辑的时间插值器，`main.js` 负责串联；
- `electron/main.mjs`：挑一个空闲端口 → 拉起 `python -m toolpath_lab` → 轮询 `/api/health` →
  装进原生窗口；关窗时结束后端。前端是普通静态文件，所以不需要打包器。

## 关键算法

### 栅格刀路

1. 把区域轮廓旋转到"走刀坐标系"：u 沿走刀方向，v 垂直于它；
2. 在 v 方向按切宽布刀，两端各内缩一个刀具足迹半径（保证刀不会切出区域）；
3. 每条刀线用 `scanline_intervals` 求交，得到它在区域内部的区间（方形是整条，圆形是一条弦，
   凹形状可以是多段）；
4. 区间两端就是这一刀的起点和终点——平面加工面下一刀两个点；
5. 往复模式奇数刀反向、刀间直接连过去；单向模式每刀同向、刀间抬到安全面再回来；
   首尾补"下刀"和"抬刀"。

### 曲面跟随（Z-map）

加工面不是平面时，上面 1—5 步的几何完全不变，只是在第 4 步之后多一步：把这一刀按
`sample_step_mm` 离散成一串 XY 点，再让每个点的 Z 取自加工面。于是"三轴曲面加工"不需要新的策略，
只需要换一个加工面对象：

- **参数化曲面**（斜面 / 波浪面）直接由公式给出 Z，采样又快又准；
- **导入模型**先把三角网格光栅化成 Z-map（每个网格节点取覆盖它的三角形的最大或最小高度，
  即"最高面 / 最低面"），采样时在节点之间做双线性插值。投影之外没有三角形的位置用最近的有效高度
  补上，并记一条提醒。Z-map 按（分辨率, 取面方式）缓存在模型对象上，
  所以同一份模型反复规划只会光栅化一次。

非平面加工面下切宽与残留高度按 XY 投影计算，实际切宽会随表面倾角变化；
安全高度也自动抬到"加工面在区域内的最高点 + 5 mm"，否则快移会穿过工件。
这些都会写进刀路 notes 或 warnings，而不是悄悄变形。

### 分层粗加工（毛坯 + 切深）

毛坯给出"材料从哪里开始切"（`box()` 的顶面），切深 ap 给出"每层切多深"，两者一起把
平面/曲面刀路变成开粗刀路：

1. 层高从毛坯顶面往下排：`Z = 顶面 − k·ap`，一直排到"加工面在区域内的最低点"之上，层数有上限（200 层）；
2. 每层改走水平刀路（`level_move()`），而且只在**该层还有材料**的地方切——判据是
   "加工面低于该层平面"：沿扫描线采样加工面高度、切成若干游程，
   游程两端再用二分求出"加工面等于层高"的交点，所以刀路端点正好落在壁上，不会留一条凸台；
3. 层内两段之间是否可以直接连刀，要核实两件事：不能跨层（换层一律抬刀横移），
   且两点之间的加工面不能高过该层（那说明中间立着材料，会撞刀）；
4. 层与层之间 `rapid_over()` 抬刀横移到下一刀正上方，再 `plunge_to()` 以**进给速度**下刀——
   这一段是在毛坯里切材料，不能用快移；
5. `finish_pass` 打开时，最后再沿加工面走一遍，把粗加工留下的 ≤ ap 余量切干净。

切深为 0（默认）时整条链路退化成"单层 + 沿加工面"，与以前的行为逐字节一致。

### 时间参数化

每段运动携带自己的进给速度，累计时间就是各段"弧长 / 进给"之和，因此快移段与切削段对"预计工时"
的贡献不同。播放时在时间轴上二分查找 + 线性插值；采样下标同时用于"已走轨迹"的绘制范围
（`setDrawRange`），不需要额外几何。

## 想动手改的时候

- 想加**参数**：在对应能力的 `ParameterSet` 里加一行 `spec(...)`，界面与校验自动跟上；
- 想加**形状**：写一个 `boundary()` 返回逆时针多边形；
- 想加**加工面**：写一个 `heights(points_xy)`，需要的话再覆盖 `sample_extremes()` 与 `note()`；
- 想加**毛坯**：写一个 `box()` 返回六个边界（圆柱毛坯、铸件毛坯……），分层粗加工与三维显示自动适配；
- 想加**策略**：继承 `Planner` 并注册，见 extending.md；
- 想加**导入格式**（STEP、OBJ、3MF……）：在 `core/mesh.py` 旁边写一个解析器，
  返回同样的 `Mesh`，上传接口与 Z-map 都不用改；
- 想加**导出格式**：在 `export/` 写一个纯函数，在 `server/app.py` 加一个分支。
