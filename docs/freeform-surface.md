# 自由曲面设计与验证

本次新增的是**解析高度场自由曲面**，不是任意 STL/STEP 模型导入。区域仍决定 XY 加工边界，曲面决定每个 XY 点的 Z 高度。

## 曲面模型

在参数面板的「曲面」区域可以选择多种解析曲面。原有「自由曲面」仍然保留，并新增纹理旋转参数；另外提供鞍形曲面、球冠/凹坑、径向波纹面和多尺度复合面，用于表达不同的正负曲率与局部细节。

自由曲面的表达式为：

```text
z(x, y) = base_z_mm
        + amplitude_mm × sin(2πx / wavelength_x_mm + phase_deg)
                       × cos(2πy / wavelength_y_mm)
```

默认值为基准高度 0 mm、幅值 4 mm、X 波长 80 mm、Y 波长 60 mm、相位 0°、旋转角 0°。多尺度复合面将长波、短波和径向波纹叠加，适合观察复杂刀路密度变化。可选区域包括方形、圆形和椭圆；栅格、交叉栅格、五轴和自适应等残留高度策略都可使用这些曲面。

## 规划与显示

平面模式保留原来的端点刀路。曲面模式根据每种曲面的最短特征尺度自动加密扫描线，再用 `height_at()` 计算每个点的 Z 值。跨刀连接在曲面上可能穿入凸起，因此曲面模式使用安全快移；安全高度为曲面理论最高点上方 5 mm。所有曲面都通过 `height_at()`、`normal_at()` 和 `height_bounds()` 接入同一套规划接口。

服务端将区域内的高度场采样为三角网格，前端以 three.js 显示曲面工件；轮廓、刀路与播放刀具使用同一高度坐标。G-code 导出包含这些三维刀点。

## 验证方式

启动窗口，在左侧「曲面」选择不同类型，观察三维工件及橙色刀路的 Z 向起伏。推荐先试「多尺度复合面」，再调小细节 X/Y 波长以观察局部起伏；也可运行：

```bash
python examples/freeform_surface_plan.py
python -m unittest discover -s tests
```

## 范围与限制

本功能用于教学演示与曲面刀路链路验证。当前不支持导入任意网格/CAD 自由曲面；五轴模式提供局部倾角接触间隙，材料切除仿真提供独立可选的高度场毛坯播放，但还没有完整的刀具扫掠碰撞检测或机床运动学求解；导出的 NC 程序不能未经验证直接用于实机加工。
