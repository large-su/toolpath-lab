# 自由曲面设计与验证

本次新增的是**解析高度场自由曲面**，不是任意 STL/STEP 模型导入。区域仍决定 XY 加工边界，曲面决定每个 XY 点的 Z 高度。

## 曲面模型

在参数面板的「曲面」区域选择「自由曲面」，即可调整基准高度、起伏幅值、X/Y 波长和相位。表达式为：

```text
z(x, y) = base_z_mm
        + amplitude_mm × sin(2πx / wavelength_x_mm + phase_deg)
                       × cos(2πy / wavelength_y_mm)
```

默认值为基准高度 0 mm、幅值 4 mm、X 波长 80 mm、Y 波长 60 mm、相位 0°。可选区域包括方形、圆形和椭圆；两种栅格策略都可使用该曲面。

## 规划与显示

平面模式保留原来的端点刀路。自由曲面模式把每条切削扫描线按最短波长的 1/24 加密，再用 `height_at()` 计算每个点的 Z 值。跨刀连接在曲面上可能穿入凸起，因此自由曲面模式使用安全快移；安全高度为曲面理论最高点上方 5 mm。

服务端将区域内的高度场采样为三角网格，前端以 three.js 显示曲面工件；轮廓、刀路与播放刀具使用同一高度坐标。G-code 导出包含这些三维刀点。

## 验证方式

启动窗口，在左侧「曲面」选择「自由曲面」，改变起伏幅值或波长，观察三维工件及橙色刀路的 Z 向起伏；也可运行：

```bash
python examples/freeform_surface_plan.py
python -m unittest discover -s tests
```

## 范围与限制

本功能用于教学演示与曲面刀路链路验证。当前不支持导入任意网格/CAD 自由曲面，也没有刀尖接触补偿、刀具与工件碰撞检测、残料仿真或机床运动学求解；导出的 NC 程序不能未经验证直接用于实机加工。
