# 交叉栅格刀路

## 功能目标

交叉栅格在同一个加工区域内生成两组方向不同的平行扫描线。它保留基座已有的
刀具半径边界内缩、进给播放、统计和 G-code 导出能力，适合需要均匀覆盖的平面
粗加工或精加工场景。

## 参数

| 参数 | 含义 | 默认值 |
| --- | --- | ---: |
| `stepover_mm` | 相邻扫描线间距 | 6 mm |
| `direction_deg` | 第一组刀线的行进方向 | 0° |
| `cross_angle_deg` | 第二组相对第一组的旋转角度 | 90° |
| `feed_mm_per_min` | 切削进给速度 | 600 mm/min |

交叉角度限制在 15°～165°，避免第二组刀路与第一组完全重合。两组之间使用安全
高度快速移动，组内使用往复连接。

## 算法流程

1. 获取区域的逆时针边界，并按刀具足迹半径向内留出安全边界。
2. 将边界变换到当前方向的局部坐标系。
3. 按 `stepover_mm` 布置扫描线，使用偶奇规则求扫描线与区域的内部区间。
4. 将区间端点内缩刀具半径，生成第一组切削段。
5. 将方向旋转 `cross_angle_deg`，重复步骤 2～4，生成第二组切削段。
6. 第一组和第二组之间抬刀到安全高度，最终抬刀结束。

## 设计特点

- 只新增一个 `Planner` 策略模块，不改变 HTTP、播放、统计和前端协议。
- 通过注册表自动进入 `/api/catalog`，前端参数面板自动生成控件。
- 组内连接和组间快速移动使用不同的 `MoveKind`，因此统计和 G-code 导出无需特殊分支。
- 方形与圆形区域均复用现有扫描线裁剪逻辑。
