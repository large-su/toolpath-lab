## 本次更新内容

1. [环切与连续螺旋](../contour-spiral.md)：凸区域内的三轴轮廓策略，沿参数化高度场采样 Z；螺旋中途不抬刀，不承诺严格等残留高度或机床动力学连续性。
2. [常用刀具库](../tool-library.md)：8 个可编辑几何预设，选择后仍可手动调整，进给速度保持不变。
3. [XY 覆盖分析](../coverage.md)：整条精加工刀路的刀具外半径圆形扫掠投影估算，不是实际材料切除率或完整五轴接触计算。
4. 仿真显示：裁剪并共享顶面网格边界，连接侧壁与底面，修复圆形及选区边缘的悬空三角片；红色覆盖层受深度遮挡，不再透视。
5. 提示交互：警告右上角增加可访问关闭按钮；关闭本条文字不停止碰撞检测，也不取消自动暂停。新异常可以再次提示。
