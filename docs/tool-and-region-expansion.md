# 刀具建模与加工区域扩展

本次扩展覆盖两个作业方向：完善刀具建模形态，以及增加可选加工区域类型。

## 刀具形态

`ToolKind` 现在开放三种刀具：

- `flat`：平底刀，刀具半径直接作为加工面足迹半径；
- `ball`：球头刀，球头刀尖接触加工面，足迹半径按 0 mm 处理，适合表达球头刀在平面上的中心轨迹；
- `bull`：圆鼻刀，增加 `nose_radius_mm` 参数。底部平直段半径为 `R - Rn`，因此刀路边界偏置量也为 `R - Rn`。

三种刀具都保留直径和长度参数。长度参与三维视图中的刀具实体显示，刀具类型和圆鼻半径会回显在规划结果中。

## 区域类型

在原有方形、圆形之外新增 `ellipse`：

| 参数 | 默认值 | 含义 |
| --- | ---: | --- |
| `major_mm` | 120 mm | 椭圆长轴长度 |
| `minor_mm` | 80 mm | 椭圆短轴长度 |
| `rotation_deg` | 0° | 椭圆相对 XY 平面的旋转角度 |

区域统一转换成逆时针边界多边形，因而现有栅格和交叉栅格算法无需分支修改就能处理椭圆。前端使用同一条边界生成拉伸工件，避免为每种区域单独编写三维实体。

## 示例请求

```json
{
  "tool": {
    "kind": "bull",
    "diameter_mm": 10,
    "length_mm": 40,
    "nose_radius_mm": 2
  },
  "region": {
    "shape": "ellipse",
    "parameters": {
      "major_mm": 120,
      "minor_mm": 80,
      "rotation_deg": 25
    }
  },
  "planner": {
    "id": "crosshatch",
    "parameters": {
      "stepover_mm": 5,
      "cross_angle_deg": 90,
      "feed_mm_per_min": 600
    }
  }
}
```

## 边界与限制

本次区域扩展仍面向 XY 平面的规则加工区域，椭圆使用 180 段折线近似。它扩展了可选轮廓类型，但还不等同于 STL/STEP 模型导入或自由曲面加工。
