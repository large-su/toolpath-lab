# 未覆盖区域显示与覆盖率分析

## 用法

生成刀路后，右上角显示“覆盖率（XY）”“未覆盖面积”和实际分析网格尺寸。
在左侧“显示”中勾选 **未覆盖区域（XY估算）**，预计漏覆盖的位置以红色标出。
此显示默认关闭，不依赖“刀路”“工件”或“材料切除仿真”的显示开关。
关闭后移除红色显示，不改变刀路或材料仿真状态。

红色贴图位于目标参数曲面上，并遵循深度遮挡，不再透过未切除毛坯显示成另一层外壳。启用材料切除仿真时，未切除的毛坯可能遮住该诊断贴图；需要单独查看完整的预计未覆盖区域时，可暂时关闭材料切除仿真。覆盖率统计仍独立于播放进度。
它不是第二个毛坯或外壳，**不是随播放更新的剩余材料**。
播放开始前即可显示整条精加工路径的预测漏覆盖区域，拖动进度不会改变覆盖率。
刀身变红与碰撞标记仍表示碰撞，与本功能的红色面状区域含义不同。

## 明显的对比例子

| 设置 | 值 |
| --- | --- |
| 刀具 | 平底刀，直径 6 mm，长度 30 mm |
| 区域 | 方形，边长 80 mm |
| 曲面 | 平面，基准高度 0 mm |
| 策略 | 栅格刀路，往复 Zigzag |
| 走刀方向 | 0° |
| 切宽 ae | 先 12 mm，再改为 3 mm |
| 显示 | 勾选“未覆盖区域（XY估算）”，使用“上”视图 |

12 mm 切宽超过刀具直径，刀线之间会出现明显红色条带。
改为 3 mm 后条带消失，覆盖率接近 100%；可能仍有少量边角未覆盖。
本次浏览器实测：12 mm 时覆盖率 57.875%、未覆盖 2696 mm²；
3 mm 时覆盖率 99.6875%、未覆盖 20 mm²（均为 0.5 mm 网格的投影估算）。
对于方形内缩刀路，圆形刀具扫掠并不能完全到达四个尖角，这是正常的几何结果。
本功能只做分析，不自动补刀，不修改原规划参数。

## 算法与接口

实现位置：`planning/coverage.py`，由 `server/service.py` 组装规划结果时调用一次。
`/api/plan` 新增 `coverage` 字段，包含百分比、面积、估算口径、网格尺寸和未覆盖格点掩码。
新增显示开关由 `/api/catalog` 的 `display` ParameterSpec 声明。

1. 在加工区域 XY 包围盒内建立格点中心网格，以奇偶规则排除边界外格点，支持凹多边形。
2. 只分析精加工 CUT 与贴面 LINK；根据 `roughing.finish_start_move_index` 排除前置粗加工，忽略所有 RAPID。
3. 计算格点到每段连续 XY 折线的最短距离，小于刀具**外径半径 R**的格点记为已覆盖。
   这是线段与半径 R 圆盘的扫掠并集，而不是刀点圆盘采样；重叠只计一次。
4. 覆盖率为已覆盖的内部格点数 / 全部内部格点数。
   覆盖面积与未覆盖面积按此比例分配区域多边形面积，两者之和等于区域面积。
5. 默认目标网格 0.5 mm，最多 40,000 个格点、单边最多 2,048；大区域自动降低分辨率，实际尺寸显示在统计中。
   若细长区域没有采到内部中心点，显示“区域过窄，网格未采到”，不虚报 0% 或 100%。
6. 未覆盖掩码作为最近邻红色透明贴图映射到目标面网格，几何边界裁剪贴图，避免区域外多出红色实体。

## 解释边界

- **这是 XY 外径扫掠覆盖估算，不是实际材料切除、到面精度、真实表面积或严格等残留分析。**
- 高度、刀尖形状和刀轴倾角均未参与覆盖距离计算：球头刀底部的真实接触面积并不是外径圆盘；
  五轴倾斜、抬高补偿或曲面起伏也可能使“投影已覆盖”但尚未切到目标面。
  曲面/圆角刀具/倾斜姿态下会额外显示“不代表实际到面”提示，不能以 100% 判断加工完成。
- 不直接使用导入 OBJ/STL 的网格作为加工高度，分析的仍是选区和当前参数曲面，延续现有导入范围。
- 格点中心、曲面三角网格和边界离散带来误差；小于一格的狭缝可能被漏估，红色边界为格状近似。
- 不保证无碰撞，不自动优化路径，不能代替机床验证。实际剩余体积请用独立材料仿真查看。
