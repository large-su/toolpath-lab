# 模型导入与区域选择

## 支持范围

界面左侧“模型导入”支持浏览器直接读取 OBJ 与 STL（三角网格）文件。模型文件只在本地浏览器内解析，
不会上传到后端或第三方服务。STEP/STP 文件需要先转换为 OBJ 或 STL。

## 区域选择

导入模型后，程序会计算模型顶点在 XY 平面的投影，并提供两种规划区域：

- **XY 投影轮廓（凸包）**：保留模型整体投影外轮廓，适合大多数粗加工演示；
- **XY 包围矩形**：使用投影包围盒，适合需要规则矩形加工区域的场景。

所选边界通过 `region.shape = "polygon"` 发送给后端，和方形、圆形、椭圆使用同一套扫描线裁剪、刀具边界偏置和
自由曲面规划逻辑。三维窗口同时显示导入的三角网格模型，刀路统计中的区域尺寸会随选择方式更新。

## 当前限制

这是一个面向刀路规划训练的轻量导入链路：投影区域使用凸包或包围矩形，不做 CAD 实体拓扑识别、孔洞提取或 STEP
特征解析。需要保留凹轮廓、孔洞或精确 CAD 面时，应先在 CAD 软件中导出目标区域边界，再扩展 `PolygonRegion` 的
边界输入或接入专用 CAD 内核。
