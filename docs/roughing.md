# 先分层粗加工

## 使用

左侧“粗加工”区域勾选“先分层粗加工”，设置“每层切深”和“精加工余量”，点击“生成刀路”。默认关闭；关闭时保留原策略生成的运动。开启时先清料，再执行所选的栅格、交叉栅格、五轴或自适应等残留高度精加工。

推荐初始设置：球头刀 D6、长度 30 mm，普通自由曲面幅值 4 mm、X/Y 波长 80/60 mm，80 mm 方形区域，每层切深 2 mm、精加工余量 0.5 mm。开启材料切除仿真和刀身检测，便于查看真实更新的剩余毛坯。默认毛坯顶部为曲面上界加 1 mm，该例生成 5 层。

紫色表示粗加工切削/进刀，精加工保持原来的橙色或自适应步距颜色，快移仍为青色。可取消“显示 → 粗加工刀路”避免多层线条遮挡。右上角显示层数、实际层切深、余量和当前加工阶段。

“跳至精加工”会暂停播放，按此前粗加工刀路重建剩余材料，再定位到精加工开始附近；不是直接把原毛坯当作已经加工。回到起点则恢复初始毛坯。粗加工增加刀路长度和预计工时，跳转按钮方便观察较长程序。

## 算法与边界

- 以默认 `stock_spec_for` 的初始毛坯顶面为起点，逐层下降到曲面下界加精加工余量。
- 每层目标刀尖高度为 `max(层高, 圆形刀具足迹邻域的曲面最高采样高度 + 余量)`。遇到凸起会抬高，不把目标曲面全部削成一个低平面。曲面参数与原精加工点、姿态不变。
- 邻域采用中心及两圈离散采样，为圆形高度场削料模型建立保护包络。余量为竖直方向，并非恒定法向余量；保护包络还会留下额外侧向材料。
- 粗加工刀轴固定 +Z。扫描步距不超过刀具直径的 35%，并且不大于已有策略的切宽（存在该参数时）。刀具中心扫描到区域边缘以清除边缘余料；刀具圆形足迹可超出投影区域，不检查外部夹具。
- 每层切深至多为教学刀具切削段轴向长度的 40%。请求值更大时自动限幅并提示，实际值在统计中显示。此规则不是实测刀具的工艺切深限制。
- 粗加工按切削进给下刀，刀间先抬至毛坯顶面以上的安全高度再横移。粗加工结束后以连续安全连接接上原精加工。
- 时间轴必须保留快移拐点和粗加工包络刀点，防止压缩后出现斜线穿过毛坯或削低凸起。采样目标预算 4000 为软预算；必要刀点可以超出。粗加工最多 128 层、250000 个扫描刀点，超过时返回可操作的错误提示。

这是高度场教学粗加工，不是完整工业 CAM 粗加工或自动避碰。它能减少未清料导致的刀身干涉，但不能保证复杂曲面、很大倾角、过短刀具或目标模型本身的干涉全部消失。粗加工与检测均不使用导入 STL/OBJ 三角网格作为真实加工面，模型仍只提供 XY 投影区域。应保留刀身检测；不能用此结果直接证明真实加工安全。

## API / 测试

`POST /api/plan` 和 `POST /api/export/gcode` 可选顶层设置：

```json
{
  "roughing": { "enabled": true, "depth_mm": 2.0, "allowance_mm": 0.5 }
}
```

Python 入口为 `run_plan(..., roughing={"enabled": True})`。`/api/catalog` 的 `roughing` 分组提供声明和默认值；刀路的 `metadata.roughing` 包含每层范围及精加工开始的运动索引。导出 NC 包含两个阶段。

- `python -m unittest tests.test_roughing -v`：目标曲面保护、层切深、策略兼容、受控进刀、连接连续性、参数校验和安全拐点保留。
- `node tests/check_roughing_integration.mjs`：需本地服务。复现 D6 / 幅值 4 / 80 mm 方形的约 4.98 s、0.21 mm 原干涉；同参数增加 5 层粗加工后，全程当前高度场刀身检测未发现干涉。
- `node tests/browser_roughing.mjs`：需现有 Playwright/Edge，验证开关、紫色刀路、阶段提示、跳转重建、回退和关闭行为。`TOOLPATH_BROWSER_MODULE` / `TOOLPATH_TEST_URL` 与碰撞界面测试相同。
