# 环切与连续螺旋刀路

本次只新增两个独立走刀策略，不替换栅格、交叉栅格、五轴、自适应或五轴自适应策略。

## 演示设置

1. 刀具库选择“平底刀 D6 · L30”。
2. 区域选择“圆形”，直径 80 mm；曲面选择“平面”，基准高度 0 mm。
3. 策略先选“环切刀路”，切宽 3 mm、采样步长 1 mm、逆时针、进给 600 mm/min。
4. 使用“上”视图观察一组闭合圆环；再选择“连续螺旋刀路”，对比从外圈向中心渐进的路径。
5. 开启“刀具”并播放。螺旋精加工只有一次下刀、一个连续切削段、一次抬刀；没有圈间快移。

为单独观察路径，可先关闭“材料切除仿真”和“未覆盖区域（XY估算）”。
毛坯边界与闭合显示已修复，未覆盖诊断层遵循深度遮挡；两项功能仍可独立开启。

## 实现区别

| 特性 | 环切刀路 | 连续螺旋刀路 |
| --- | --- | --- |
| 路径组织 | 每圈都是闭合、固定偏置的轮廓 | 外圈完整走一圈，逐圈渐进内收，内圈闭合后到中心 |
| 精加工运动段 | 多个 CUT，圈间 LINK 或安全 RAPID | 单个 CUT，只有首尾 RAPID |
| 平面圈间连接 | 选区内进给连接 | 不单独连接，过渡包含在每次旋转中 |
| 曲面处理 | 逐点跟随高度场，圈间从全局安全高度跨越 | 切削点贴合高度场，整条路径连续 |
| 绕向 | 顺时针 / 逆时针 | 顺时针 / 逆时针 |
| 中心 | 最后内圈之后进给到内部中心 | 最后内圈闭合后连续到内部中心 |

参数由两个策略的 ParameterSet 发布。原有 `/api/plan`、时间轴、通用 NC 导出和前置粗加工直接复用。
统计增加“偏置圈数”，螺旋增加“连续切削 1 段（精加工）”；开启粗加工时，总刀轨数还包括粗加工刀轨。

### 几何

- 方形、圆形、椭圆和导入投影的凸多边形边界均可使用；圆/椭圆沿用原区域的多边形离散。
- 对逆时针边界每条边向内平移，取所有半平面的交集生成内缩环，避免偏置塌陷后生成反向轮廓。
- 边界内缩距离沿用现有刀具的加工面足迹半径：平底 R、圆鼻 R−Rn、球头 0。
  这是本项目的教学几何约定，不是整把刀具或倾斜姿态的严格贴壁间隙。
- 环切保留每一个原始顶点；螺旋把相邻内缩环按归一化弧长对应，沿一次旋转线性混合：
  `P(t) = (1−t) A(t) + t B(t)`，`0 ≤ t ≤ 1`。
- 采样加入两个轮廓的拐角位置；曲面进一步按原有特征尺度加密。播放保留刀点，避免时间轴抽稀跨过方形拐角。
- 曲面只改变 Z，刀轴仍竖直。两种新增策略是三轴策略，**并非五轴螺旋或严格等残留加工**。

### 适用边界

- 暂不支持凹选区、孔洞、多连通区域或自交边界；会返回说明，建议改用栅格/交叉栅格，不静默跨过凹口。
- 最多 720 个边界点、512 个偏置环、10 万个精加工刀点；超过预算会要求增大切宽/采样步长或缩小区域。
- “连续”指路径没有中途抬刀/连接断点，不意味着方形拐角达到曲率连续或机床加速度约束。
- 过渡是轮廓插值，非任意曲面的严格等距/等残留；切宽大于刀径时会提醒可能漏加工。
- 没有加入自动避碰。复杂曲面建议先粗加工并检查已有碰撞提示；实际机床使用必须另做后处理和验证。
