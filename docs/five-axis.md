# 五轴加工功能

## 功能范围

`five_axis` 是一个教学演示用的五轴曲面刀路策略。它复用现有的区域扫描线裁剪和自由曲面高度场，在每个 XYZ 接触点计算刀轴方向，并把刀轴姿态传递到：

- `Move.tool_axes`：与 `Move.points` 一一对应的单位向量；
- 播放时间轴：对刀轴做最短大圆插值，支持原地转向时间；
- three.js 视口：刀具局部 +Z 轴跟随刀轴旋转；
- G-code：用 `A=方位角`、`B=相对 +Z 的倾角` 输出演示姿态。

## 姿态计算

曲面法向为 `normal`，沿走刀方向的曲面切向量为 `tangent`，横向切向量为 `side`。给定前倾角 `lead_deg` 和侧倾角 `side_tilt_deg`，刀轴为：

```text
axis = normalize(
    normal
    + tan(lead_deg)      × tangent
    + tan(side_tilt_deg) × side
)
```

在平面上，`normal` 为 `[0, 0, 1]`；在自由曲面上，法向随 XY 位置变化。正前倾表示刀轴朝走刀方向倾斜，侧倾角控制横向倾斜。

## 可关闭的姿态平滑

“五轴姿态平滑”默认开启。三个设置为：

- 平滑范围：默认 6 mm。在每刀的 XY 走刀距离上，用对称高斯权重平均邻近刀轴，并以局部采样间距加权，避免只按刀点数量滤波。大范围能减缓局部摆动，但不跨刀混合相反的走刀方向。
- 最大姿态偏差：默认 5°。将平滑结果限制在原法向加前倾/侧倾刀轴的夹角邻域；0° 保留原切削刀轴，但仍使用安全转向与角速度约束。平底/圆鼻刀的接触补偿必须按新刀轴重新计算。平面仍保持恒定姿态，不人为添加摆动。
- 刀轴角速度上限：默认 30°/s。每条运动折线边的仿真时间为 `max(平移距离 / 进给速度, 刀轴夹角 / 角速度上限)`；过快时延长该小段时间，而不是允许更大姿态偏差。纯转向即使 XYZ 不变也会占用时间。

开启后，换行在平面和曲面上均先抬刀，保持出刀姿态；只在安全高度的横移段转到下一刀的姿态，然后保持该姿态下刀。粗加工转入五轴精加工的连接也使用同一角速度上限。切削与连接的原刀点在时间轴中必须保留，避免载荷压缩跳过姿态拐点。显示、任意时刻的材料仿真和碰撞扫描统一采用有向单位刀轴的大圆插值，正负刀轴不视为同一姿态。

右上角显示平滑前后最大的刀轴变化率（°/mm，按 XY 走刀距离）、实际最大偏差和仿真峰值角速度。可关闭开关进行原始姿态对比；不同曲面的平滑收益不同。此滤波并非保证全局最优，也未限制角加速度或 jerk。

插值原则参考 [SciPy 官方 Slerp 文档](https://docs.scipy.org/doc/scipy/reference/generated/scipy.spatial.transform.Slerp.html)；本项目仅用 NumPy 实现刀轴方向的大圆插值，不增加 SciPy 依赖，也不处理刀轴绕自身的主轴转动。

## 使用

在界面左侧「刀路」选择「五轴曲面刀路」，然后设置切宽、走刀方向、前倾角、侧倾角和进给速度；曲面选择「自由曲面」时可以同时观察曲面起伏和姿态变化。播放条右侧会实时显示当前刀位的 `A/B` 姿态；若选择平面，界面会提示法向恒定、同一刀路姿态保持一致是预期行为。无界面示例：

```bash
python examples/five_axis_plan.py
```

可用“多尺度复合面”，细节 X/Y 波长 18/20 mm、五轴前倾 18°、侧倾 5°，平滑范围 8 mm、最大偏差 5°、角速度上限 10°/s，观察开关对比。降低角速度上限会增加预计工时，不会把曲面变平。若需清料，请另外开启“先分层粗加工”，并保留材料切除和刀身检测。

## 安全边界

五轴策略仍然使用曲面最高点以上 5 mm 的安全高度。自由曲面切削段会按加密后的每个刀点重算法向和刀轴；平底刀、圆鼻刀会按局部倾角增加保守接触间隙，球头刀保持刀尖相切。当前仍没有实现机床旋转轴限位、奇异点检测、完整刀具扫掠碰撞检测、RTCP/刀尖点控制或后处理器坐标转换。

因此导出的 A/B 代码仅用于教学和仿真验证。实际加工前必须根据具体机床的 A/B/C 轴方向、零点、摆头/转台结构、RTCP 设置和后处理器重新生成并仿真。

导出的演示 A 方位角会沿最近的 ±360° 等价角展开，避免数值从 +179° 跳到 -179°；零倾角处沿用上一方位角。但这不解决机床奇异点，展开后的 A 也可能超出真实旋转轴限位。仿真角速度上限不是实际 A/B 轴速度上限；NC 会明确标注 `simulation-only`，当前导出不包含相应的逆时间进给或旋转轴运动学后处理。

验证入口：`python -m unittest tests.test_orientation_smoothing`、`node --test tests/test_orientation.mjs`、`node tests/browser_orientation.mjs`（浏览器测试需本地服务及现有 Edge/Playwright 环境）。

要同时使用自适应刀路间距，选择独立的 [五轴自适应等残留高度](five-axis-adaptive.md)。该球头刀教学策略共用本节的姿态与平滑模块，原 `five_axis` 仍使用固定切宽。
