# 自适应等残留高度刀路

## 功能目标

该策略用于复现文献中常见的等残留高度思想：给定目标残留高度，估算相邻刀路
之间允许的最大步距；曲面变化较快的区域自动减小步距，平坦区域使用较大的
步距。它与原有的栅格刀路使用同一套区域裁剪、曲面采样、时间轴和 G-code 导出
接口，因此可以在同一个模型上直接比较。

## 计算方法

对于等效刀尖圆弧半径 `R` 和目标残留高度 `h`，先使用球头刀弓高关系反解平坦
区域的理论步距：

```text
s0 = 2 √(2 R h - h²)
```

球头刀使用刀具半径，圆鼻刀使用鼻圆角半径；平底刀没有刀尖圆弧，因此采用刀具
半径作保守近似，并在刀路说明中标注。

在每一个候选刀路位置，沿相邻刀路方向取局部高度场样本，用中心差分估计二阶变化：

```text
k ≈ |z(v + δ) - 2z(v) + z(v - δ)| / δ²
```

再用曲率因子缩小步距：

```text
s = clip(s0 / √(1 + 4 R k), s_min, s_max)
```

每条刀线沿走刀方向取多个样本，并采用其中最大的局部曲率，避免只在刀线中点
采样而漏掉峰值。最后一刀会对齐到加工区域边界，保证区域覆盖完整。

## 界面参数

| 参数 | 含义 |
| --- | --- |
| 走刀模式 | 往复或单向走刀 |
| 目标残留高度 | 相邻刀路的理论最大残留高度 |
| 最小步距 | 高曲率区域允许的最小横向步距 |
| 最大步距 | 平坦区域允许的最大横向步距 |
| 走刀方向 | 刀线方向，步距沿其法向计算 |
| 进给速度 | 切削段进给速度 |

生成自适应刀路后，右侧统计卡会显示目标残留高度和实际步距范围。左侧“自适应
步距着色”默认开启：暖色表示步距较小、刀路较密，蓝绿色表示步距较大、刀路较
稀；关闭该选项即可恢复统一的橙色刀路。该颜色只对自适应等残留高度策略生效，
其他策略不会改变显示。

## 复现实验建议

使用相同的自由曲面分别生成交叉栅格和自适应等残留高度刀路，记录刀路数量、
切削长度、预计工时和步距变化。将自由曲面的起伏幅值或波长调大，可以观察到
高曲率区域的刀线明显变密；将曲面切换为平面时，步距会回到理论基准值。

该实现用于教学和方法复现，曲率估计采用解析高度场的有限差分，尚未替代工业
CAM 中基于精确刀具扫掠体的残留高度和碰撞求解。

如需同时改变刀轴，选择独立的 [五轴自适应等残留高度](five-axis-adaptive.md) 策略；当前仅支持球头刀，仍属于目标残留估算，不保证真实倾斜刀具扫掠下严格等残留。原 `adaptive_scallop` 仍保持竖直刀轴。
